# Todo List

## 📌 Açıklama

Todo List, günlük yapılacak işleri kolay ve düzenli bir şekilde takip etmeyi sağlayan basit bir görev yönetimi uygulamasıdır. Kullanıcılar uygulama üzerinden yeni görevler ekleyebilir, mevcut görevlerini düzenleyebilir, tamamladıkları görevleri işaretleyebilir ve artık ihtiyaç duymadıkları görevleri silebilir.

Bu proje, temel CRUD işlemlerini ve kullanıcı etkileşimlerini öğrenmek amacıyla geliştirilmiştir.

Bu projenin amacı, kullanıcıların günlük görevlerini daha düzenli bir şekilde yönetmesini sağlamak ve JavaScript ile temel web uygulaması geliştirme becerilerini geliştirmektir.
